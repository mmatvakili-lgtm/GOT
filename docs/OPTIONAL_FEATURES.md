# قابلیت‌های اختیاری و تنظیمات (assets/balance.properties)

همهٔ قابلیت‌های زیر پیش‌فرض **خاموش**‌اند.

## فعال‌سازی (روش اصلی)
صفحهٔ ورود ← پنل ادمین (با رمز) ← دکمهٔ **Features Control Center**. سه صفحه (بات‌ها، رویدادهای فصلی، درخت تحقیق) با توضیح هر گزینه، کلید روشن/خاموش، اسلایدر با بازه و مقدار پیش‌فرض، پریست‌ها و خلاصهٔ زنده. تغییرات تا زدن **Apply changes** ذخیره نمی‌شوند و با یک نوشتن امن در `balance.properties` ثبت می‌شوند. بات‌ها در بازیِ جدید اضافه می‌شوند؛ رویدادها و تحقیق فوراً اعمال می‌شوند.

روش دستی: تغییر مقدار در `balance.properties` و راه‌اندازی دوبارهٔ بازی.

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `bots.count` | 0 | تعداد بات‌ها در بازی (جای خالی بازیکن‌ها، حداکثر ۷ نفر در کل). بات‌ها فقط داخل فایل بازی هستند، نه در `users/`. |
| `bots.garrison` | 30 | سرباز اولیهٔ هر بات. |
| `bots.growth.perDay` | 0 | سرباز رایگان اضافه در هر روز بازی (۰ تا ۵۰). |
| `bots.garrison.max` | 200 | سقف سرباز بات برای رشد روزانه. |
| `bots.build.enabled` | 0 | ۱ = هر بات هر روز یک ساختمان می‌سازد: معدن/انبار رایگان اول، ارتقای قلعه، Camp، Barrack، بعد اقتصاد بیشتر. همان قوانین و هزینهٔ بازیکن. |
| `bots.train.perDay` | 0 | تعداد سربازی که بات با Barrack در هر روز آموزش می‌دهد (۰ تا ۵۰). |
| `bots.attack.enabled` | 0 | ۱ = بات‌ها به بازیکن‌ها حمله می‌کنند (همان قوانین؛ پیمان صلح/اتحاد محافظ است؛ هشدار فوری به هدف). |
| `bots.attack.startDay` | 10 | تا این روز بازی حمله نمی‌کنند. |
| `bots.attack.days` | 7 | حداقل فاصلهٔ دو حملهٔ هر بات. |
| `bots.attack.strength` | 50 | درصد سربازانی که می‌فرستد؛ بقیه در خانه می‌مانند. |
| `diplomacy.enabled` | 0 | ۱ = پیمان صلح و اتحاد بین بازیکن‌ها (Extra > Diplomacy). |
| `diplomacy.peace.days` | 10 | مدت پیمان صلح. |
| `events.enabled` | 0 | ۱ = رویدادهای فصلی (برداشت خوب، قحطی، رونق تجارت). |
| `events.chance.percent` | 15 | احتمال رویداد در هر روز بازی. |
| `events.effect.percent` | 10 | اندازهٔ اثر رویداد (درصد انبار)، برای همهٔ قلمروها یکسان. |
| `research.enabled` | 0 | ۱ = درخت تحقیق (منوی Extra). |
| `research.cost.percent` | 100 | درصد هزینهٔ تحقیق (۱۰ تا ۵۰۰). |
| `research.time.percent` | 100 | درصد زمان تحقیق (۱۰ تا ۱۰۰۰). |
| `battle.*` | | ضرایب تعادل نبرد (ردیف‌ها، قهرمان، کمین، وینترفل، ایری). |

## فایل‌های جدید کنار بازی
- `logs/got.log`: لاگ بازی (با چرخش در ۲ مگابایت)
- `leaderboard.txt`: رتبه‌بندی کلی بازیکنان (بدون بات)
- `settings.properties`: صدای موسیقی و افکت
- `*.ser.bak`: نسخهٔ پشتیبان خودکار فایل بازی

## بخش‌هایی که در لابی اضافه شد
- **Leaderboard**: رتبه‌بندی کلی و دستاوردهای بازیکن فعلی
- **Settings**: صدای موسیقی و افکت‌ها
